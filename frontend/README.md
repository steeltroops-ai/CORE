# CORE Frontend

Next.js App Router interface for the Commercialization & Research Evaluator (CORE).

## Quickstart
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Visit `http://localhost:3000` to explore the MVP UI.

## Layout Overview
- Research Ingestor with upload form and status stepper.
- Insight workspace tabs mapping to Patent Radar, Stakeholder Map, VC Dashboard, and GTM Studio.
- Agent console stub ready for Beyond Presence integration.
- Narration player stub to connect ElevenLabs during polish phase.
- Demo controls for curated presets and Lovable deployment rehearsal.
